# Plan d'action CRO — BOT-WOW et sites Sargasses

Trois horizons : 24h, 7j, 30j.

## Principe directeur
Chaque page vend. Un CTA par zone, texte court et orienté bénéfice, ancrage descriptif, pas de pop-up agressif.

## Contraintes légales
- BOT-WOW : pas de CTA « Acheter maintenant » irrévocable tant que le logiciel final n'est pas livré (précommande uniquement).
- Sargasses : ne pas modifier prix ni conditions existantes. Respecter CGV, droit de rétractation, RGPD.

- actions-24h.md : actions rapides, impact élevé
- actions-7j.md : travaux moyens
- actions-30j.md : changements lourds
