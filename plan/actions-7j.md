# Plan d'action — 7 jours (travaux moyens)

## Objectif
Améliorer la visibilité mobile, capturer des leads B2B, et optimiser la performance des pages critiques.

## Actions

### 1. Composant sticky mobile
- [ ] Développer le bouton sticky bas « Alertes Sargasses » sur pages carte et prévisions (Martinique + Guadeloupe)
- [ ] Tester visibilité sur iOS Safari et Chrome Android (pas de scroll horizontal)

### 2. Formulaires de capture
- [ ] BOT-WOW : mini-formulaire « Liste d'attente » (email uniquement) si paiement désactivé
- [ ] Sargasses : vérifier que le formulaire B2B (nom, email, plage) est court et accessible sur mobile

### 3. Performance
- [ ] Compresser images et cartes (lazy-loading, attribut alt sur toutes les images/cartes)
- [ ] Tester vitesse des pages critiques avec Lighthouse (page d'accueil, carte, offres)
- [ ] Charger les scripts de tracking de manière asynchrone

### 4. Tests A/B ou qualitatifs
- [ ] Si trafic ≥ 500 VU/mois : lancer A/B sur la page d'accueil (couleur ou wording du CTA principal)
- [ ] Sinon : tests utilisateurs ou heatmaps sur les CTA clés

### 5. Contenu et SEO
- [ ] Mettre à jour les meta descriptions pour chaque langue (fr/en/es)
- [ ] Créer un lien depuis les réseaux sociaux « Notre réseau sargasses » vers le site principal
- [ ] Préparer un article de blog sur la fiabilité des données sargasses

## Livrables
- Bouton sticky mobile fonctionnel
- Formulaire B2B optimisé mobile
- Score Lighthouse ≥ 80 sur pages critiques
- Rapport de test A/B ou qualitatif
