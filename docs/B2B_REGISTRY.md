## 4. Règles de relance

- Une relance est **préparée** (objet + corps + lien de désabonnement) dans `scripts/automation/data/b2b-followups/`.
- **Aucun envoi automatique** : l’envoi exige une autorisation explicite du fondateur.
- Un prospect `won` ou `lost` n’a plus de relance préparée.
- Une adresse en bounce n’est jamais recontactée.
- Le taux de réponse et le taux de démo sont calculés, jamais estimés.
