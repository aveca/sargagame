# Problem Journal — Sargagame B2B

> **Règle** : Noter CHAQUE problème entendu chez les prospects. Ne jamais chercher de solution immédiatement. Chercher les problèmes **répétitifs** pour lesquels quelqu'un paierait.

---

## Comment remplir

Pour chaque contact (hôtel, office, restaurant, club, etc.) :

```
### [Nom] — [Type] — [Lieu] — [Date]

**Problème entendu** : [ce qu'ils disent]
**Mots exacts** : "[citation directe]"
**Fréquence** : [estiment: 1x/semaine, tous les jours, saison uniquement]
**Impact** : [perte clients, avis négatifs, remboursement, stress, etc.]
**Solution actuelle** : [ce qu'ils font aujourd'hui pour gérer]
**Réaction au pitch** : [intéressé / sceptique / pas le temps / trop cher / etc.]
```
