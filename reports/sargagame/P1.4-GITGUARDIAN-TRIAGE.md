## 4. Qualification du finding GitGuardian `39170333`

### Cause du déclenchement

Le littéral `'.htpasswd'` apparaît dans `scripts/prepare-ftp.cjs` à la ligne de définition de `COPY_SKIP_TOP`, sous la forme d'un **nom de fichier** dans une liste d'exclusion d'assets statiques. Il ne s'agit **pas** d'un contenu de fichier `.htpasswd`, ni d'un mot de passe, ni d'une clé d'authentification.

Aucun fichier `.htpasswd` n'existe dans le dépôt (ni à la racine, ni dans aucun sous-répertoire). Aucun secret n'est présent dans le diff de la PR.

### Qualification

**Faux positif prouvé :** le token `.htpasswd` est un identifiant de fichier d'exclusion, pas un secret d'authentification. Le but du correctif est précisément d'empêcher `.htaccess` et `.htpasswd` d'être servis comme assets statiques Cloudflare — c'est une mesure de sécurité, pas une fuite.

### Limites

- Le dashboard GitGuardian n'a pas été consulté (pas d'accès disponible). Le message d'erreur du check GitHub indique uniquement `failure` sans détail sur le détecteur déclenché ni sur la ligne exacte incriminée.
- La qualification repose sur l'analyse statique du diff et du contexte du littéral `.htpasswd` dans le code.
